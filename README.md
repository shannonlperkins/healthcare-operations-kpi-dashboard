# Healthcare Operations KPI Dashboard

## Executive Overview

This portfolio project demonstrates how operational data can be transformed into an executive-level performance dashboard for an ambulatory healthcare organization.

The dashboard uses entirely synthetic data and was designed to demonstrate capabilities in healthcare operations, business analytics, KPI development, performance management, and executive decision support.

## Business Problem

Healthcare leaders are often responsible for performance across multiple operational areas, including patient access, provider capacity, productivity, staffing, patient experience, and financial performance.

When these measures are reviewed independently, emerging operational problems can be difficult to identify.

This project demonstrates how key performance indicators can be consolidated into a single leadership view to support faster and more informed operational decisions.

## Dashboard Objectives

The dashboard is designed to help healthcare leaders:

* Monitor organizational performance against established targets
* Identify patient access and capacity constraints
* Evaluate provider productivity and schedule utilization
* Detect operational trends requiring intervention
* Monitor patient experience performance
* Assess staffing and workflow effectiveness
* Compare financial performance against budget
* Prioritize operational improvement opportunities

## Key Performance Indicators

The dashboard includes measures related to:

### Patient Access

* New-patient appointment availability
* Visit demand
* Scheduling performance

### Provider Performance

* Provider utilization
* Schedule utilization
* Template utilization
* Visit volume

### Patient Experience

* Overall patient experience
* Likelihood to recommend
* Ease of scheduling
* Staff teamwork

### Operational Performance

* Call answer rate
* Staffing performance
* Workflow efficiency

### Financial Performance

* Revenue versus budget
* Productivity trends
* Operational variance
